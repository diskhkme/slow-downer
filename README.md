# Slow Downer

연주 연습용 오디오 플레이어. 곡을 느리게(피치 유지) 또는 다른 키로 재생하고, 구간을 반복하며 연습한다.

- 속도 25–150% (피치 유지), 피치 ±12반음 (템포 유지). 느린 속도에서도 드럼이 두 번 들리지 않는 타임스트레치
- 파형 위에서 드래그해 루프 만들기, 곡당 여러 루프, 경계 10ms 미세 조정
- 곡별 설정 자동 저장 (속도, 피치, 볼륨, EQ, 루프, 마지막 위치). 파일을 옮겨도 같은 곡으로 알아본다
- 곡 간 음량 자동 평준화
- 플레이리스트 여러 개
- 출력 장치 선택. 기타 앰프 시뮬레이터 같은 ASIO 앱과 같은 오디오 인터페이스로 함께 소리를 낼 수 있다

Windows 11 64비트 (Windows 10에서는 확인하지 않았다).

## 설치

[Releases](https://github.com/diskhkme/slow-downer/releases)에서 `Slow Downer_<버전>_x64-setup.exe`를 받아 실행한다.

- 코드 서명이 없어 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누른다.
- 현재 사용자용으로 설치되며 관리자 권한이 필요 없다.
- 새 버전은 그냥 덮어 설치하면 된다. 플레이리스트와 곡별 설정은 유지된다.
- 처음 실행할 때 마이크 권한을 물을 수 있다. 출력 장치 이름을 보여 주는 데만 쓰며 녹음은 하지 않는다
  (거부하면 출력 장치 목록에 "시스템 기본 장치"만 보인다).
- 제거는 Windows 설정 > 앱에서.

## 사용법

| 동작 | 방법 |
|---|---|
| 곡 추가 | `+ 곡 추가`, 또는 탐색기에서 창으로 끌어다 놓기 (mp3, wav, flac, m4a, aac, ogg, opus) |
| 곡 순서 / 이름 | 끌어서 순서 변경 (파란 선이 놓일 위치) · 더블클릭으로 이름 변경 |
| 플레이리스트 | 왼쪽 위 선택상자로 전환 · `+` 새로 만들기 · `✎` 이름 변경 · 🗑 삭제 (두 번 눌러 확인) |
| 재생 / 일시정지 | `Enter` (또는 ▶ 버튼) |
| 정지 후 루프 처음으로 | `Space` (루프가 켜져 있을 때. 꺼져 있으면 재생/일시정지) |
| 탐색 | 파형 또는 시간 눈금 클릭 |
| 확대 / 이동 | 휠 = 확대·축소 (마우스 위치 기준) · 우클릭 드래그 또는 `Shift`+휠 = 좌우 이동 |
| 루프 만들기 | 파형 위를 드래그 |
| 루프 조정 | 영역 양 끝을 드래그 · `[` `]` 시작점 ±10ms · `Shift`+`[` `]` 끝점 ±10ms |
| 루프 켜기/끄기 | `L` (또는 루프 열의 켜짐/꺼짐 버튼) |
| 루프 선택 / 이름 | 오른쪽 루프 목록이나 파형의 영역 클릭 · 더블클릭으로 이름 변경 |
| 속도 / 피치 | 슬라이더 빈 곳 클릭 = 10% / 1반음씩 · 속도 옆 `−` `+` = 1%씩 · 숫자 직접 입력 |
| 볼륨 / EQ | 슬라이더 (더블클릭 = 0 dB). 볼륨은 자동 보정 위에 더하는 값 |

단축키는 한글 입력 상태에서도 동작한다.

### 데이터 위치

플레이리스트와 곡별 설정은 `%APPDATA%\com.hkkim.slowdowner\`에 저장된다.
다시 설치하거나 업데이트해도 남고, 제거할 때 "앱 데이터 삭제"를 체크하면 함께 지워진다.
백업하거나 다른 PC로 옮길 때는 이 폴더를 복사한다
(곡 위치가 다르면 곡을 다시 추가하면 된다. 같은 파일이면 설정이 이어진다).
